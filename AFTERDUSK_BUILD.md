# Afterdusk CUDA 12.8 build

This repository packages the MIT-licensed RunPod Chatterbox Turbo worker for Blackwell-compatible RunPod GPUs.
The worker logic originates from `owen-tech-ramblings/token-gen-chatterbox-runpod`; this variant changes only the CUDA/PyTorch base to CUDA 12.8 / PyTorch 2.9 and adds a GHCR build workflow.
No Afterdusk application secrets or private character/user data are included.
